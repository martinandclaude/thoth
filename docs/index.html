Weigh your pipeline against the truth.

thoth weighs every pipeline the same way, every time. Hold yours against GIAB's truth sets — v4.2.1, v5.0q and CMRG — and let the scales decide: devoured by Ammit, or admitted to the Field of Reeds we call prod.

In the old judgement, Anubis weighed the heart against the feather of Ma'at while Thoth wrote down the verdict. Here the feather is GIAB and Anubis's scales are hap.py and truvari — and, as the results below show, the verdict depends on how carefully those scales are set.

Choice 1 · the truth set

The same calls get a different score from each truth set

One DeepVariant callset, scored three times — against GIAB v4.2.1, the newer T2T-based v5.0q, and the CMRG set of 273 medically relevant genes. SNPs barely move. Indels do not: v5.0q reaches into repeats and complex regions that v4.2.1 excluded, so it finds misses that the older benchmark could not see.

Choice 2 · reporting one number or many

A headline recall hides where a caller actually fails

The same calls against v4.2.1, broken down by GIAB's genome stratifications. The overall figure is dominated by easy sequence; the difficult parts of the genome — repeats, segmental duplications, low mappability, the MHC — are where callers differ and where clinically relevant variants hide.

Choice 3 · comparing records or haplotypes

Structural variants: the same event can be written more than one way

GIAB v5.0q, unlike earlier benchmarks, keeps complex SVs — and a complex event has several valid representations. A caller that writes it differently from the truth is scored as a miss plus a false call, unless the comparison re-aligns the region and compares haplotypes instead of records. GIAB's own README for v5.0q recommends exactly that:

truvari bench --refine --pick ac -r 2000 -C 5000

Choice 4 · reading a threshold

A 70 % sequence-similarity threshold passes unrelated sequence

truvari's default pctseq 0.7 sounds strict. But its similarity is (len_a + len_b − edit distance) / (len_a + len_b), and under that measure two completely unrelated random sequences of the same length score 71–74 % (median, 50 bp to 5 kb). From 200 bp, every such pair passes. An insertion of the right size at the right place is matched whatever its sequence — so SV insertion precision is really a size-and-position precision.

Reproducible by construction

Every number can be traced to the exact bytes that produced it

Each variant tool thoth runs is published by this repository's own CI as a single container image file: bcftools, samtools and truvari built from pinned sources, hap.py converted unchanged from a community image pinned by digest. Each file is tested, given a signed build-provenance attestation, and published by content digest. A cluster only downloads and verifies those files; it never builds or converts anything. Each run writes a provenance record with the commit, the merged configuration, every image digest and the checksum of every truth file used.
